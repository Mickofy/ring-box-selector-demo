# Ring Box Selector Demo

Interactive Shopify-style product detail page prototype for a custom **Ring Box Selector** feature.

## Demo features

- Jewelry product detail page layout
- Ring selector with 3 products per row
- Selected-ring state
- Box color options
- Quantity controls
- Simulated **Add Box + Ring to Cart**
- Cart drawer showing both items
- Responsive desktop/mobile layout

## Shopify implementation

This repository is a front-end prototype using sample products. A production Shopify implementation would use:

- Liquid
- Shopify section schema
- Theme Editor product picker blocks
- Real product and variant IDs
- Product availability handling
- Shopify Ajax Cart API
- Theme-specific cart drawer refresh logic
